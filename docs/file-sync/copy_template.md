# copy_template.ps1

## 位置

`scripts/file-sync/copy_template.ps1`

## 用途

通用文件/目录复制模板。支持多任务、多目标目录、白名单/黑名单范围和两种目标处理模式。

## 核心函数

`Copy-FilesWithProgress`

### 参数

- `SourceDir`：源目录。
- `DestDirs`：一个或多个目标目录。
- `Mode`：`Sync` 或 `Mirror`。
- `Files`：可选白名单，只复制指定文件或目录。
- `Exclude`：可选黑名单，复制整体目录但排除指定项。
- `Title`：任务标题。
- `Enabled`：是否启用任务。

`Files` 和 `Exclude` 不能同时使用。

## 模式说明

- `Sync`：复制新增或变化文件，保留目标目录中的额外文件。
- `Mirror`：复制选定源文件，并删除目标目录中的额外文件。

## 主要流程

1. 校验任务参数。
2. 创建缺失的目标目录。
3. 按完整目录、白名单或黑名单模式扫描源文件。
4. 对比文件大小和修改时间，跳过相同文件。
5. 将变化文件复制到所有目标目录。
6. 在 `Mirror` 模式中删除目标目录的多余文件和空目录。
7. 输出单任务和总任务统计。

## 当前任务

## 风险

运行前请检查启用任务。错误的 `Mirror` 目标会导致文件被删除。
